# Reto ABC

Sitio del abecedario inglés A–Z con explicaciones en español.

## Abrir el proyecto

Abre `index.html` en un navegador. Las imágenes, los estilos y el JavaScript están guardados localmente; no se necesita instalar dependencias ni conectarse a internet para visualizar la galería.

## Actividad implementada

- 26 letras ordenadas, cada una con su palabra, traducción e imagen.
- Se corrigieron letras equivocadas, títulos incompletos y rutas de imágenes.
- `style.css` vinculado: fondo gris, encabezados h3 verdes, clase `texto-azul` aplicada a tres h3 y clase `texto-rojo` aplicada a un h3.
- `script.js` vinculado: cualquier h5 cambia al azar entre verde, azul y rojo al hacer clic. Se excluye el color actual para que cada clic produzca un cambio visible.
- El botón del encabezado permite activar la misma interacción con teclado.
- Diseño adaptable e índice de navegación por letras.

## Imágenes

Se conservaron las fotografías entregadas en `Pictures`. Las imágenes faltantes de C, D, O, P, Q, R, S, T e Y se obtuvieron de las miniaturas de los artículos de Wikipedia correspondientes. `Pictures/sources.json` conserva las direcciones de procedencia. Las direcciones registradas permiten consultar los artículos y acceder a las fichas de Wikimedia Commons, sus autores y sus licencias.
