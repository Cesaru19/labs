# Bitácora web

Autor: Cesar Joseph Luna Chiu.

## Abrir el sitio

Abre `index.html`. El sitio funciona localmente y no necesita instalaciones ni conexión a internet.

## Páginas

- `index.html`: inicio con tres notas sobre desarrollo web e imágenes locales.
- `sobre-mi.html`: autoría y propósito del proyecto.
- `contacto.html`: correo y teléfono proporcionados por el autor.

Las tres páginas usan únicamente `style.css`, el mismo menú siempre visible al desplazarse y el mismo pie de página. La estructura sigue `Pic/Bad_Template.jpg`: tres enlaces superiores, contenido central y pie de página. Las dos ilustraciones SVG se crearon para este sitio.

Los datos de contacto fueron proporcionados por el autor. No se incluyeron datos biográficos adicionales ni se habilitó un formulario de envío de mensajes.

GitHub y Replit se omiten por indicación del usuario. El archivo `BACKLOG.md` documenta las tareas locales y su estado; no es un tablero publicado en GitHub.
