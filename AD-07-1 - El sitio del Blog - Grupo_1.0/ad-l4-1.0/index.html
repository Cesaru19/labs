Notas de desarrollo

HTML · CSS · Diseño

01 / Estructura

Antes del color, el contenido

El HTML organiza lo que cuenta una página. Un título presenta la idea principal; los párrafos la desarrollan y las imágenes ayudan a explicarla.

Etiquetas como <nav>, <main> y <footer> permiten reconocer la navegación, el contenido y el cierre del sitio. Una estructura clara facilita leerlo y mantenerlo.

Una idea para practicar

Escribe primero el contenido sin estilos. Comprueba que los títulos sigan un orden y que cada enlace describa su destino.

02 / Presentación

El espacio también comunica

CSS define cómo se presenta el contenido. El tamaño de letra, la separación entre bloques y el contraste pueden hacer que una lectura resulte cómoda.

Una sola hoja de estilos permite que varias páginas compartan colores, márgenes y tipografía. Así, el visitante reconoce el mismo sitio al cambiar de sección.

Una idea para practicar

Prueba diferentes anchos de ventana. Si una imagen se sale de su contenedor o el texto queda demasiado apretado, ajusta el diseño para pantallas pequeñas.

03 / Navegación

Tres páginas, una misma experiencia

El menú superior conecta Inicio, Sobre mí y Contacto. Permanece visible al desplazarte y señala la sección en la que estás. El pie de página reúne el nombre del proyecto, la autoría y el correo de demostración.
